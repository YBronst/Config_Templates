# What's this?

So, you clicked the "Database" button in OCAT to generate a preconfigured OpenCore EFI for your Intel processor, but all you got was a pop-up redirecting you to a broken link? 

Well, the OCAT developer removed direct access to the configuration templates stored in the database, but the link they provided instead doesn't exist. I created this repository in the hopes that the developer will eventually update OCAT with a working link to it. This will make it much easier to maintain and update the configuration files.
